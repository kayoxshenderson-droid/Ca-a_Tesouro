# Caça ao Tesouro

Jogo de aventura em texto, para o terminal, feito em Python como exercício de lógica de programação.

O jogador faz escolhas (esquerda ou direita, nadar ou esperar, qual porta abrir). Cada resposta leva a um caminho diferente, e só uma sequência encontra o tesouro. O jogo usa ASCII art na abertura e na vitória.

## O que pratiquei

- Entrada do usuário com `input()`
- Estruturas condicionais aninhadas (`if` / `elif` / `else`)
- Normalização de texto com `.lower()`
- Strings de várias linhas para a arte em ASCII

## Como executar

```bash
python Caça_Tesouro.py
```
